**Executive Summary**

This study explores the implementation and effectiveness of data encryption and privacy protection technologies within contemporary cloud computing environments, driven by the critical need to address escalating security threats. The research responds to recent findings indicating a 37% increase in global cloud data breach incidents, with sensitive personal information involved in 78% of cases, and highlights that unauthorized access remains the most common threat, accounting for 45% of security issues. To evaluate protective mechanisms, the researchers constructed a simulated private cloud platform using OpenStack, deploying 20 virtual machine instances connected via a 1Gbps Ethernet through a Cisco Nexus switch. The investigation systematically assessed encryption algorithms, including AES, RSA, and homomorphic encryption, alongside privacy protection techniques such as data masking (e.g., partial masking of phone and ID numbers), secure multi-party computation (SMPC), and differential privacy (implementing both Laplace and exponential mechanisms).

The experimental phase utilized test datasets comprising 1GB of structured data and 5GB of unstructured data, including a user behavior dataset containing one million records, confirming the practical viability of the implemented solutions. Performance metrics demonstrated robust results, with the AES-256 encryption speed achieving 350MB/s and decryption reaching 380MB/s. Furthermore, a malicious behavior detection system successfully identified and blocked 97 out of 100 simulated attacks, maintaining a false positive rate controlled below 3%. Advanced security protocols, such as a zero-knowledge proof where the core is proving the relationship $mody=gx modp$ without revealing the private key $x$, were extended for application in attribute-based access control systems. To further optimize overall system performance while ensuring high security, a hybrid approach incorporating parallel processing techniques was innovatively introduced.

The evaluation of specialized privacy techniques confirmed their efficiency in complex scenarios, such as the SMPC simulation involving three banks jointly performing credit scoring, where the calculation for 1,000 users took approximately 5 seconds, incurring a communication overhead of about 2MB per participant. The security architecture was further bolstered by integrating core security components including firewalls, an intrusion detection system, and a VPN gateway. Overall, system performance and security tests confirm that the deployed solutions effectively support the stringent data security and privacy protection needs inherent in large-scale cloud environments, providing a comprehensive technical implementation and evaluation reference for future cloud security architectures.
