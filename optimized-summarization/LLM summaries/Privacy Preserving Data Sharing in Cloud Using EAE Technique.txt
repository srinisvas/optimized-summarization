Executive Summary
This paper addresses the significant security and privacy challenges arising from outsourcing sensitive data to untrusted third-party cloud computing environments, recognizing that while cloud storage is cost-effective, data management and retrieval become complex. Although Attribute-Based Encryption (ABE) schemes offer resistance against common attacks, existing encryption approaches are hindered by the demand for greater processing time and the need for secure communications during the transport of sensitive information. To mitigate these limitations and provide a unique framework for achieving both secure transmission and information secrecy, the research proposes the Enhanced Elliptic Curve Attribute-based Encryption (EAE) scheme, an approach inspired by Identity-based encryption, which is designed to ensure user privacy during data transmission.

The EAE methodology integrates Elliptical Curve Cryptography (ECC), recognized as a powerful and secure mechanism for cloud application development, which utilizes elliptic curves for core functions such as digital signatures and pseudo-random generation. The core process involves EAE encrypting user data during transmission and then applying the EAE approach within a basic hash function to generate a collision-free hash value for the encrypted data, which is subsequently stored on the cloud server. To reinforce data transfer security, this generated hash value is securely transmitted to the associated cloud users. Furthermore, the developed scheme incorporates a new ABE technique specifically designed to safeguard user privacy during the key provision process, thereby mitigating risks such as compromised communication anonymity if the Central Authority (CA) were to be compromised.

Experimental evaluation investigated and assessed the performance of the proposed EAE scheme against existing strategies, demonstrating that EAE is both effective and versatile for the secure outsourcing of data in the cloud environment. A critical finding is that the EAE technique requires less time to execute compared to other existing methods, while still enabling the establishment of scalable, flexible, and powerful data access policies. The work concludes that EAE offers a new and efficient encryption methodology for providing safe data access, making it highly suitable for various privacy situations, particularly those involving commercial large datasets in the cloud.
