Executive Summary

This paper addresses the critical privacy concerns arising from the increasing use of public cloud solutions by organizations seeking to share valuable documents for data mining and research purposes. Given that secret information is stored and managed by service providers, traditional privacy protections, such as HIPAA for health data, are often inadequate for modern cloud scenarios. To mitigate these risks, the research proposes and implements a privacy-preserving application environment on a private cloud, intending later to publish the privacy-protected documents to a public cloud through a hybrid cloud approach. This methodology is particularly relevant for organizations that require stringent data governance while maintaining necessary data utility for external collaboration.

The core of the proposed solution involves the design and implementation of a cost-effective private cloud infrastructure using the open-source software OpenStack, which is a collection of software projects utilized to provision and manage large networks of virtual machines. This experimental setup employed a three-node architecture, where the Cloud Controller (Server1) handles API processes, MySQL, and Keystone, while the Compute Node (Server2) runs the hypervisor and the `novacompute` process necessary for VM creation and resource allocation. Within this environment, privacy preservation models were implemented, utilizing methods such as k-anonymity, which groups similar data and anonymizes each group individually to minimize information loss during data protection.

The experimental setup of OpenStack proved to be highly suitable for small, mid-sized, and large organizations, institutions, and research centers requiring a cost-effective infrastructure that emphasizes both high efficiency and security. The implemented privacy preservation models for data management are highly beneficial to organizations that share sensitive cloud data with the outside world. Future work is focused on enhancing the private cloud’s performance by integrating additional nodes into the infrastructure and completing the design and setup of the full hybrid cloud model required for securely sharing sensitive information with the public cloud for publishing.
