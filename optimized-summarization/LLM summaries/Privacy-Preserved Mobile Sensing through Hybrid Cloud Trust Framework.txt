**Executive Summary**
Revolutionary applications such as personalized intelligent computing, health behavior monitoring, and future activity prediction are enabled by mobile sensing, which collects personal, fine-grained Big Data that can scale up to several Gigabytes per day per user. Typical sensor information includes GPS, accelerometers, call logs, and browsing history. However, the collection and processing of this detailed personal data present a critical privacy obstacle, as users do not trust the public cloud to store and process their information, which has serious privacy consequences if not protected. This lack of trust significantly limits the acceptance rate of mobile sensing technology, which was initially documented at 23% among surveyed users, despite 87% being aware their smartphones contain tracking sensors.

To address this widespread privacy anxiety, the paper proposes a novel sensing framework utilizing a hybrid cloud combined with a trusted third-party certification mechanism. This approach ensures decentralized data aggregation by distributing computing across mobile devices, a personal cloud, and a public cloud. Raw sensor data, collected in indexed file storage chunks (e.g., split every 1 hour), is stored exclusively within the personal cloud, which consists of virtual machines deployed on users’ own physical machines. This structure provides the user with full physical control, allowing them to use a web UI to manage their raw data, create specific sensing profiles, and authorize feature extraction apps through a specified procedure.

Data consumers do not directly access the raw data; instead, they authorize the installation of an analytic "widget" onto the user's personal cloud. This widget 1) declares the specific information it will extract, 2) runs locally on the personal cloud using the data analytics API to process the raw sensor data, and 3) uploads only the extracted analytics to the public cloud, ensuring the private data remains localized. Furthermore, the framework introduces a trusted third party, which must share no interest with data consumers, to certificate the behavior of applications, thereby increasing the difficulty of publishing data malware. This trust paradigm, which also defines different sensitivity levels and categorizes data widgets accordingly, successfully reduced users' privacy anxiety, increasing the acceptance rate of the mobile sensing technology from 23% to 60%.
