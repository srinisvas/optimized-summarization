Executive Summary
This research addresses the critical challenge of ensuring privacy-preserving data dissemination within B2B Service-Oriented Architectures (SOA) where services interact and share data hosted in untrusted cloud environments, such as encrypted key-value stores. The inherent vulnerability arises when the cloud platform hosting the shared database cannot be trusted, requiring assurance that each service can access only its authorized data segments while simultaneously detecting potential data leakages. To resolve this, the authors designed and prototyped a novel cloud enterprise framework that ensures privacy-preserving dissemination of data, providing both confidentiality and integrity without relying on a Trusted Third Party (TTP) to issue decryption keys for recipient services, thereby eliminating a central point of trust failure.

The core of the proposed solution is the "Active Bundle," an entity in which data and policies are made inseparable. Data dissemination is governed by a robust access mechanism evaluated against four key factors: role-based access control, the cryptographic capabilities of the client’s browser, the client’s authentication method, and the subject’s trust level. Based on the evaluation of these criteria, the Active Bundle responds to the requesting service with only the authorized data. Access control policies can be specified using either JSON or XACML policy languages, and the framework uniquely supports complex policies that can be written in Java. Furthermore, micro-policies are defined using tags (labeling URLs, network connections, etc.) and a transfer function that monitors security-relevant browser operations to define permitted actions.

The implementation, demonstrated through a prototype for the privacy-preserving dissemination of Electronic Health Records (EHRs) hosted in an untrusted cloud environment, confirms the framework’s efficacy. This methodology is shown to provide protection against eavesdropping attacks, with the Active Bundle incorporating an embedded tamper-resistance mechanism. Key contributions include the ability for multiple parties (services) to update the data, support for complex and context-dependent dissemination logic based on client attributes (such as the client’s network status), and the elimination of reliance on the data owner’s constant availability. The decryption key derivation procedure is designed to be analogous to the encryption key derivation, facilitating secure access where recipients are not known in advance.
