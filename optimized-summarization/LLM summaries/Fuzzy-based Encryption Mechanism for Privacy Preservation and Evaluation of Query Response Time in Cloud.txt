Executive Summary
This research addresses the critical need for enhanced security in data mining by mitigating privacy leaks and unauthorized access prevalent in earlier studies, particularly at the edge layer where analysts obtain data. The protection offered by public infrastructure is insufficient, necessitating a robust mechanism for privacy preservation. To secure both data processing (safe uploading by the data owner) and query processing (safe data analyst access), the study introduces a system design utilizing a fuzzy-based encryption mechanism that incorporates the Laplace mechanism for Differential Privacy (DP). This approach is designed to introduce noise into the dataset, thereby protecting the privacy of personal data, with the sensitivity property determining the necessary parameters for effective management of accuracy and privacy.

The proposed system involves the Data Owner, Data Provider, Edge Server, Cloud, and Data Analyst, with the methodology detailed across three sub-sections: System Design, Data Processing, and Query Processing. In the data processing phase, the Data Owner, regarded as a trusted entity, performs DP and encrypts the dataset using the portable Piccolo algorithm before transferring it to the public cloud, which is considered untrustworthy. For query processing, the Data Analyst makes requests that are authenticated by the Data Provider. Hashed queries are exclusively accepted by authorized data analysts for searching. The edge server's hash tree subsequently locates matching data, retrieves the cipher text from the cloud, and forwards it in an encrypted format. Cloud data extraction results in cipher text that requires a specific decryption key provided only to each verified Data Analyst to access the query result.

Experimental validation was performed using MATLAB 2020a, running on a specified configuration, and involved processing scenarios considering 5000 edges and 1,000 vertices. The outcomes demonstrate that the system design is more efficient than prior research regarding improved throughput, response time, and encryption time, confirming its scalability and accuracy in the field. The research concludes that the proposed architecture successfully facilitates safe data analyst access to secure data. Future work intends to improve the fuzzy model by adding more trustworthy entities to address potential single point failures and to further expand the work by adding DP for privacy protection in conjunction with hybrid machine learning algorithms.
