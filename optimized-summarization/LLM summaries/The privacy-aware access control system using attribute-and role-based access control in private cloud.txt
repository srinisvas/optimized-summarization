Executive Summary
Cloud computing has introduced significant advancements to the IT industry, enabling users to avoid upfront hardware investments and gain flexibility, but security remains a critical issue for cloud users, particularly concerning access control, user profile management, and data privacy within private cloud environments. Addressing these unmitigated concerns, this paper proposes a privacy enhancement system implemented on an Academic-based private cloud system utilizing the Eucalyptus open-source cloud infrastructure. The core contribution is the introduction of the ARBAC (Attribute- and Role-Based Access Control) model, which combines the strengths of Role-based Access Control and Attribute-based Access Control. This hybrid approach is applied to improve user privacy and security for private personal data, supporting both mandatory and discretionary access control needs on the target system.

The proposed system framework is designed to allow the cloud client to store and upload their data in the cloud according to predetermined privacy standards or laws, and subsequently access that data according to defined user levels. In the ARBAC model, service providers publish well-defined access control requirements within policy statements. Policy representation is made more fine-grained within the ABAC component, as decisions can be based on any combination of subject, resource, and environment attributes. Subject attributes describe the user taking action on a resource, including identifier, organization, and job title, while environment attributes describe the operational context of access, such as time and location. Resources themselves also have attributes that are leveraged to make comprehensive access control decisions.

The operational security protocol mandates that before invoking services, requestors must provide their attribute information and all parameters of the method they intend to access. The system assumes a set of roles authorized to perform specific actions, and that users are authorized to play those roles, classifying data security levels based on significance and sensitivity. The foundational premise requires that information collected must be adequate, relevant, and not excessive, with the purpose for data collection being explicitly mentioned. Furthermore, access control rules ensure data integrity and lifecycle management, stipulating that no one shall have the ability to delete Personally Identifiable Information until the appropriate time period has expired. Authorization flow determines that if the requested access permission is granted by the relevant policy entry, access is granted; otherwise, access is denied.
