Executive Summary

The widespread adoption of Cloud Computing necessitates robust mechanisms to ensure user privacy and security, particularly concerning sensitive identity information that is either directly provided or derived from secondary data like IP addresses. To address this challenge, this paper introduces the Preserving cloud computing Privacy (PccP) model, a three-level architecture designed to enhance the privacy of cloud users. The architecture comprises the Consumer Layer, which manages user access to cloud services; the Network Interface Layer, which ensures IP address privacy by mapping original user IP addresses to a modified set of Owned Translated IP addresses (OTIPs) generated from an IP address pool; and the Privacy Preserved Layer.

The core function of the Privacy Preserved Layer is the generation of a unique User Service Dependent Identity (USID) using a proposed algorithm within the Unique User Cloud Identity Generator. This layer solves the problem of sensitive information being provided directly to the cloud service provider by applying data obfuscation and de-obfuscation techniques, thereby preventing the provider from directly accessing the data. To generate the USID, the OTIPs and a timestamp are used in a mapping function to select an identity from a pool of available IDs. This process incorporates a match logic mechanism to cross-check the generated USID against a list of already created IDs, ensuring uniqueness and preventing the allocation of any privacy leaked identities.

Central to the PccP model is a Privacy Check method based on information privacy that enforces user control. This method utilizes the user’s Personalized Data Attributes (PDA’s) and a Boolean function called Transparency Purpose in Cloud (TPC) to allow the user to specify which identity attributes must remain privacy protected and transparent from the cloud service provider. By masking the original user identities and providing services based solely on the service-dependent USID—which may result in multiple USIDs per user—the model prevents the direct access or derivation of sensitive identification information. This assurance of identity privacy encourages greater user confidence and access to cloud services, ultimately promoting economies of scale.
